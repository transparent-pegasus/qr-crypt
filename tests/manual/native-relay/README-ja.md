# Windows 11 x64 手動 E2E

案内された成功 CI の `native-relay-windows-developer-<コミット SHA>` アーティファクトを使います。EXE、ビルド情報、この手順、人工サンプルが同じ ZIP に入っています。

対象は QR Crypt の Windows 中継版です。鍵の生成・暗号化・復号は行いません。検証用データは既存の自動テストから生成した人工フレームで、実際の秘密鍵や平文を含まず、暗号学的に有効なメッセージではありません。形式、表示、カメラ、コピー操作を確認するために使います。

QR Crypt の鍵・識別子・平文を現在または過去に扱った端末、オフライン版を導入した端末では実施しないでください。別のオンライン Windows PC と同梱の人工データを使います。カメラに映る周囲にも注意してください。

## 起動まで

1. 案内されたアーティファクトをダウンロードし、ZIP 内のファイルを同じフォルダーへすべて展開します。`qr-crypt-relay.exe`、`build.json`、`README-ja.md`、`manifest.json` とサンプル 7 ファイルがあります。
2. 展開先で PowerShell を開き、次を実行します。表示されたコミット SHA と EXE の SHA-256 を、ダウンロード先とともに案内された値と照合してください。不一致なら起動せず、その結果を記録します。

   ```powershell
   $build = Get-Content -LiteralPath .\build.json -Raw | ConvertFrom-Json
   $hash = (Get-FileHash -Algorithm SHA256 -LiteralPath .\qr-crypt-relay.exe).Hash.ToLowerInvariant()
   $build.source
   $hash
   if ($hash -cne $build.executable_sha256) { throw 'EXE と build.json が一致しません' }
   ```

   `build.json.source` は EXE のビルド元です。`manifest.json.source` はサンプル生成時の履歴で、EXE のビルド元とは別です。ZIP 内の値同士の一致だけでは、案内された候補との一致を確認したことにはなりません。

3. EXE を通常のユーザー権限で開きます。管理者として実行する必要はありません。Windows が実行をブロックした場合は、その表示とビルド番号を記録してください。
4. WebView2 Runtime が必要です。Windows 11 に含まれますが、未導入の環境では Microsoft の公式配布先を使います。アプリの起動自体が失敗した場合は、ウィンドウが出たか、エラー表示があったかを記録してください。([Microsoft の説明](https://learn.microsoft.com/en-us/microsoft-edge/webview2/concepts/distribution)、[公式 Runtime 配布先](https://developer.microsoft.com/en-us/microsoft-edge/webview2/))
5. 言語を「日本語」にし、タイトルが「QR Crypt リレー」であることと、表示されたビルドが `build.json.source` と一致することを確認します。

## カメラを使わない確認

| 操作                                                                                                | 期待する結果                                                                                 |
| --------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------- |
| `sym-message.txt` をメモ帳で開き、全文を「テキスト → QR」の「中継テキスト」に貼り付け、「QRを表示」 | QR が 1 枚表示される                                                                         |
| 閉じて、同じ画面を開き直す                                                                          | 入力と QR が残っていない                                                                     |
| `pq-message.txt` の 2 行をまとめて貼り付け、「QRを表示」                                            | 2 フレームが再生される。フレーム数が 2 と分かる                                              |
| 再生中にウィンドウを最小化し、戻して「テキスト → QR」を開く                                         | 再生が自動再開せず、入力と QR が空になっている                                               |
| `rejected-non-message.txt` を貼り付け、「QRを表示」                                                 | 外側ヘッダーが pq-message または sym-message を表明していないというエラー。QR は表示されない |
| 入力・再生後にアプリを終了し、開き直す                                                              | メッセージは復元されない。言語設定は残ってよい                                               |

## 実カメラとコピーの確認

別のオンライン端末の画面で同梱の PNG を表示するか、人工サンプルだけを印刷して Windows のカメラに見せます。`qr-samples.html` は同じフォルダーの PNG を表示するだけの補助ページです。カメラがない場合は、この範囲を未実施と記録してください。

| 操作                                                                                               | 期待する結果                                                               |
| -------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------- |
| 「QR → テキスト」を開く                                                                            | 「カメラを開始」を押す前にはカメラが動作しない                             |
| 「カメラを開始」を押し、必要なカメラ許可を与え、`sym-frame-1.png` を読み取る                       | 1 行の中継テキストが得られ、読取り完了後にカメラが停止する                 |
| 「中継テキストをコピー」を押し、メモ帳へ貼り付ける                                                 | `sym-message.txt` と同じ 1 行になる                                        |
| 新しいセッションで `pq-frame-1.png`、`pq-frame-2.png` を順に読み取り、コピーしてメモ帳へ貼り付ける | 途中は収集数が表示され、揃うと `pq-message.txt` と同じ 2 行になる          |
| 「QR → QR」で `sym-frame-1.png` を読み取り、「QR画像をコピー」を押してペイントへ貼り付ける         | QR が画像として貼り付く                                                    |
| 新しい「QR → QR」で PQ のフレームを読み取る                                                        | 複数フレーム用の「QR → テキスト」を使うよう案内される                      |
| カメラ動作中にアプリを最小化し、元に戻す                                                           | カメラが停止し、自動で再開しない。次の読取りには再度「カメラを開始」が必要 |

コピー後の内容は Windows のクリップボードに残ることがあります。アプリ内セッションの消去と、OS や貼り付け先での消去は別です。
