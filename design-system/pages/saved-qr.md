# /saved — 保存済みQRページ

MASTER.md を継承。md 以上のみ max-width 42rem。

## 構成

1. h1「保存済みQR」+ 件数
2. フィルター(Tabs または Select): すべて / 暗号文 / 鍵(共通鍵・公開鍵)。既定=すべて
3. 一覧(新しい順)。空状態: 「保存済みのQRはありません」+ /encrypt への導線

## 一覧行(Card、spec §14 の表示項目)

- 1 行目: 名前(font-medium、省略) + 機密度バッジ(公開/機密/最高機密。**最高機密は TriangleAlert 常時表示**)
- 2 行目(mono, muted): 種別(暗号文/共通鍵/公開鍵)・方式・データサイズ(bytes)
- 3 行目(muted, 0.8125rem): 作成日時 / 最終表示日時 / 鍵ID(または受信者鍵ID)先頭 8 文字… / SHA-256 先頭 8 hex…
- 行タップ → 詳細シート(Sheet)。行内 DropdownMenu: 表示 / 名前を変更 / PNG / SVG / コピー / 削除

## 詳細シート

- 全メタデータ(名前・種別・方式・作成日時・サイズ・鍵ID・機密度・SHA-256 全体 mono・最終表示日時)
- 「QRを表示」ボタン → QrDisplay(白面・全画面可)。表示時に lastViewedAt 更新
- **最高機密(共通鍵・秘密鍵バックアップ)**: 表示・PNG・SVG・コピーの前に強確認(「リスクを理解しました」チェック)。シート上部に警告帯(destructive 面+spec §10.1 警告文)
- 機密(暗号文): 通常確認なしで表示可
- 名前変更: Dialog + Input(1〜80 文字・制御文字禁止、qrNameSchema)
- 削除: AlertDialog。最高機密は強確認+「この鍵のQRを削除しても、アプリ内の鍵本体は削除されません」等の正確な説明

## 挙動

- PNG/SVG ファイル名は `<sanitized-name>-<shortId>.<ext>`(秘密情報を含めない、spec §14)
- コピーは payload 文字列。最高機密はコピー後トーストで「クリップボード同期に注意してください」
- 並びは createdAt 降順固定(ソート UI なし。シンプル優先)
