# /keys — 鍵管理ページ

MASTER.md を継承。`Tabs`: 共通鍵 / 公開鍵ペア / 鍵を読み取る(spec §10)。

## 共通鍵タブ

- 先頭: 「共通鍵を生成」フォーム(鍵名 Input + 生成ボタン primary)。生成後は一覧先頭に追加しトースト
- 一覧(Card 行): 鍵名 / 指紋(mono 4×4)/ 作成日時 / 使用回数 / 最終使用日時 / 機密度バッジ「最高機密」
- 行操作(DropdownMenu): QR を表示 / 名前を変更 / 削除
- **共通鍵 QR 表示前に必ず警告 AlertDialog**(spec §10.1 文言そのまま):
  「このQRコードには暗号化と復号に使用できる秘密鍵が含まれています。撮影、画面共有、クラウド同期された場合、暗号文を復号される可能性があります。」
  → 「表示する」で QrDisplay(白面、全画面可、警告バッジ常時表示)
- QR 画面の操作: 命名(自動提案 `共通鍵-<鍵名>`)/ アプリ内保存 / PNG / SVG / コピー。
  **保存・PNG・SVG・コピーは強確認**(「リスクを理解しました」チェックで活性化。spec §10.1「通常より強い確認」)
- 削除: AlertDialog(通常確認)+「この鍵で復号できなくなります」説明
- 重複: 生成/取込時に指紋一致があれば DUPLICATE_KEY 文言+既存鍵名を表示し保存しない

## 公開鍵ペアタブ

- 「鍵ペアを生成」フォーム(鍵ペア名+生成ボタン)。RSA-3072 生成は数秒かかる → ボタン内 spinner+「生成中…(数秒かかります)」、二重実行防止
- 一覧行: 鍵ペア名 / 公開鍵指紋 / 作成日時 / 使用回数 / 秘密鍵の状態バッジ(「秘密鍵あり」success 面 / 「公開鍵のみ」secondary+「この端末では復号できません」注記)
- 行操作: 公開鍵 QR を表示(警告不要。機密度=公開バッジ)/ 公開鍵をファイル出力(`.txt`、OCP1 ペイロード)/ 名前を変更 / 削除
- 公開鍵 QR 画面: 命名(提案 `公開鍵-<鍵ペア名>`)/ 保存 / PNG / SVG / コピー(通常確認)
- 削除: 秘密鍵ありの場合は**強確認**+「この鍵ペア宛の暗号文は二度と復号できなくなります」。公開鍵のみは通常確認
- 秘密鍵は QR 表示・エクスポート UI を出さない(`enablePrivateKeyExport=false` 固定。メニューに項目自体を出さない)

## 鍵を読み取るタブ

1. 読取対象を先に選択(RadioGroup 縦 44px): 「共通鍵を読み取る」/「公開鍵を読み取る」(spec §16。暗号文の読取は /encrypt 復号タブ)
2. 「カメラを起動」ボタン → QrScannerDialog(カメラ権限はこの時点で要求)
3. 読取成功 → 確認カード: 種別 / 方式 / 指紋(4×4 mono、照合を促す文言「相手の画面の指紋と一致することを確認してください」)/ 作成日時 + 鍵名入力(提案 `共通鍵-取込` 等)
   - 選択した対象種別とプレフィックス不一致 → 拒否文言(例: 「これは公開鍵のQRです。読取対象を切り替えてください」)
   - 共通鍵の保存は追加確認(チェックボックス「この鍵の共有経路を信頼しています」)
   - 指紋重複 → DUPLICATE_KEY(既存鍵名提示、保存不可)
4. 失敗: CAMERA_PERMISSION_DENIED / CAMERA_NOT_AVAILABLE を文言+対処(設定アプリで許可 等)で表示

## QrScannerDialog 共通規則

- 開いたときのみ getUserMedia。閉じる(成功・キャンセル・エラーいずれも)でストリーム必ず停止
- 読取成功時は即ロック(多重発火防止)、ビープ等の音は鳴らさない、読取画像を保存しない
- 枠ガイド+「QRコードを枠内に合わせてください」、`aria-live` で状態通知
